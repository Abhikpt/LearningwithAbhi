# Blazor learning journey

Welcome to the Learning page. This content is loaded from **wwwroot/data/learning.md** when the GitHub API is unavailable (for example on GitHub Pages or if the remote repo path is wrong).

## What you can explore on this site

- **Demos** — components, forms, routing, and UI patterns under Demo Site
- **Tools** — calculators, PDF helpers, image tools under Web Tools
- **Practice** — automation-friendly pages for hands-on testing

## Run locally with full API support

1. Start the **Server** project: `dotnet run` from `LearningwithAbhi/Server`
2. Open the URL shown in the console (for example `https://localhost:7294`)
3. Navigate to `/learning`

To load markdown from GitHub instead, set `GitHub:Owner`, `GitHub:Repo`, and `GitHub:DefaultFile` in `Server/appsettings.json`.
